# 《李富贵》分镜镜头脚本 · 四大财子段（初中）粤语版 · AI 短剧

> 源文本：李富贵自传"四大财子"段落
> 人物：李富贵（主角）+ 李栋雄（稳重组织者）+ 冯威捷（机灵消息灵通）+ 薛致远（文青忧郁写诗）
> 语言：全篇粤语对白 + 粤语旁白
> 时代锚定：90s 广州初中（约 13-15 岁，1998-2000）
> 视觉基调：90s 广州中学 · 市井烟火 · 现实主义克制 · 童年回忆略带暖色
> AI 短剧适配：竖屏 9:16 · 35mm 胶片 · 版权规避（武侠/卡带不出 IP，用氛围）

---

## 【制作基线】

- **源剧本版本**：李富贵叙事文本（四大财子段）
- **转换范围**：单段落 → 7 子场景 / 24 镜头
- **输出模式**：画面版（分镜镜头脚本，AI 短剧向）
- **视觉总纲**：90s 广州中学 + 老巷子市井，克制不煽情，"我"的代入感视角
- **模拟摄影机 / 胶片**：35mm 胶片（Kodak Vision3 250D 日 / 500T 夜），颗粒中低，黑位略抬，肤色偏暖
- **镜头组 / 等效焦段**：中焦 50mm 为主，操场夕阳 85mm 浅焦，课堂 35mm 广角
- **画幅 / 帧率**：竖屏 9:16 / 24fps（胶片感）/ 快门 180°
- **景深**：浅景深 F2.0-2.8，夕阳戏边缘虚化光斑
- **光色 / 调色**：暖色降饱和，市井烟火，夕阳那场最暖
- **运镜基线**：课堂稳定，操场夕阳缓慢推/摇，克制
- **声音基线**：只写叙事性环境声（吊扇、翻书、操场哨声、卡带机"咔哒"），**不写配乐/BGM**
- **版权规避**：武侠小说 / 流行卡带一律**不生成具体 IP 封面/角色脸**，用"泛光封面剪影 / 卡带机 / 磁带盒侧标"表达"在交换/在看"；"四大财子"戏称落到**黑板粉笔字 / 贴墙纸条**

### 场景 2-1　初中教室 · 走廊　日 / 内→外
人物：李富贵（14 岁）、同学若干

△全景。90s 广州中学教室，木课桌成排，吊扇打转，黑板上有没擦净的粉笔字，窗外是 90s 广州骑楼街。

△中景，富贵放学走进走廊，站住，望向窗外。远处巷口一辆 90s 广州无盖老式公交（铁皮、木扶手、绿涂装）驶过，"叮"一声明显，把思绪拉回。

△近景，富贵手插口袋，指节偏细，神情平静（沉静底色）。

旁白（粤语，男声，中年回望）：
> 初中，我哋分咗去唔同嘅中学。就系喺度，我遇到咗李栋雄、冯威捷、同薛致远。

### 场景 2-2　教室 · "四大财子"起头　日 / 内　【名字由来】
人物：李富贵、李栋雄、冯威捷、薛致远、起头同学（侧/背影）

△中景，下课时间，四个少年凑喺一排座位，桌面上摊住武侠小说、卡带盒。

△近景，一个调皮同学（背影）拿粉笔喺黑板上画四个圈，写"四大财子"，指住四人笑。

△特写，黑板粉笔字"四大财子"，旁边歪歪扭扭画四个火柴人。

△近景，四人有反应。
冯威捷（粤语，机灵）：
> 喂喂，"四大财子"？我哋叫咁好犀利呀！
薛致远（粤语，闷声）：
> ……有冇可能换个名。
李栋雄（粤语，稳重）：
> 就咁啦，贴切。
富贵（粤语，不抬头）：
> 随便。

△特写，"四大财子"四字留在黑板，成为小团体代号。

旁白（粤语）：
> 唔知系边个先起咗个头，因为我哋四个嘅名字，多少都带着点对"兴旺发达"嘅期许，就被戏称为"四大财子"。最初系玩笑，后来就成为咗我哋小团体嘅代号。

## 三、AI 分镜生成说明（喂 Kling / Sora / 可灵 / Seedance）

1. **逐镜成段**：把"画面内容 + 粤语旁白/台词 + 声音 + AI 提示关键词"拼一段，逐镜生成再按镜号拼接。
1.5. **⭐旁白粤语锁定（pavo-ai 内置 TTS · 防普腔 · 本段必带）**：
   - **根因**：pavo-ai 等工具内置旁白 TTS **默认按普通话读**——旁白文本虽是粤语口语，也会被读成普通话腔。**语言锁定必须直接写进提示词本身**（给外部 TTS MP3 的工作流在 pavo-ai 上不适用）。
   - **执行**：每镜拼段时，旁白文本前**永远紧跟一行语言锁定（中英都写）**：
     `旁白为粤语（广东话 / Cantonese / Yue Chinese）男声画外音朗读，禁止普通话（NOT Mandarin），保留粤语口癖（嘅/咗/唔/㗎）；旁白属画外音 VO，画面中人物不张嘴、不配台词。`
   - 若工具旁白/语音设置里有语种选项，**一律选 粤语 / Yue / Cantonese**，不得选 普通话 / Mandarin / CN。
2. **武侠 / 卡带版权规避（关键）**：
   - 镜 13/17 武侠小说、镜 14/15 卡带，**不要让 AI 生成可辨认的具体 IP 封面/角色/歌手**。
   - 统一用"封面泛光剪影 + 书脊 + 卡带盒侧手写标签 + 磁带转动"表达"在看/在交换"，观众凭台词与氛围就能 get。
3. **"四大财子"戏称**：落到**黑板手写字 + 四个火柴人**（镜 5/6/8），比口头交代更有画面记忆点。
