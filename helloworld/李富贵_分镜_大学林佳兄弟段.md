# 《李富贵》分镜镜头脚本 · 大学林佳兄弟段 · 2004→2006（粤语版）· AI 短剧 · 【第一人称 POV + 少旁白·演绎优先】

> 源文本：李富贵自传"大一下学期，我在学校的编程兴趣小组里认识了林佳。她是计算机系的，短发，利落，讨论问题时眼神专注，一针见血。我们因为一个项目组队，合作异常默契。我惊讶地发现，和她相处很轻松，不用刻意找话题，就像和'四大财子'在一起时一样。她知道我和亭娜的事（在一次聚会醉酒后，我不小心说了出来），后来有一次，她抱着一堆书在我常去的自习室找到我，把一瓶冰镇可乐'砰'地放在我面前，说：'李富贵，为个异地的前女友丧眉耷眼，像什么样子。走，帮我看段代码去，我请你吃宵夜。'她的语气没有安慰，只有一种哥们儿式的、不容置疑的明朗。那一刻，我忽然觉得胸口淤积的什么东西散开了一些。从那以后，我们真的成了'兄弟'。一起泡图书馆，一起在机房通宵调试程序，一起吐槽食堂的饭菜，一起在操场跑步。她在我因为复杂的语法头疼时，能随手画出清晰的树状图；我在她陷入递归死循环时，往往能一眼看出问题。我们互相兜底，无话不谈。"
> 人物：李富贵（POV 主视角，19-21 岁·英语专业）、**林佳（计算机系女生·本段正面登场）**、兴趣小组同学（背景）、大排档老板（背景）
> 亭娜：**本段不出现**——只作画外之伤（醉酒说漏 + "异地嘅前女友"一句）
> 语言：全篇粤语对白 + 粤语内心独白（**第一人称当下口吻 · 真粤语口语**）
> 时代锚定：**广州 2004 → 2006**（大一下学期 → 毕业前；互联网盛行前夜 → 兴起）
> 取景锚定：**广东培正学院**（架空层长廊活动室 / 机房 / 图书馆三楼自习区 / 饭堂 / 操场）+ 校门外**大排档**（宵夜锚）
> 情感基调：**全片第一段"回暖"**——由上段的"匿埋"到"被人拉出来"。**不是爱情戏，是兄弟戏**：林佳的方式 = 不安慰、不点破、只拉走。全段从冷蓝逐步回暖，宵夜场最暖
> 承接：上段《大学避难所段》U-7 机房（2006）林佳背影 + 可乐"砰"铺垫 → 本段正面登场；"砰"为本段声音主角
>
> **本版强化点**：
> ① **少旁白 · 演绎优先**——全段独白仅 **4 句**（同上段铁律：叙述性独白全删、改为可见动作；静音校验法）
> ② **第一人称 POV**——富贵全段不出正脸（我的手/视线/肩/后脑勺）；**林佳可出正脸**（她是"被看的人"，同亭娜规则）
> ③ **多机位**——A·POV / B·过肩OTS / C·细节反打 / D·空镜呼吸点
> ④ **"砰"三重声音锚**——上段 U39 砰（背影铺垫）→ 本段 L22 大砰（核心场）→ L32 叩轻（收束呼应），同一支玻璃樽可乐，三次力度，一段关系
> ⑤ **全粤语对白**——林佳语速快、句子短、唔绕弯（人设锁），可直接喂 TTS

## 【制作基线】

- **源剧本版本**：李富贵叙事文本（大学·林佳兄弟段）
- **转换范围**：单段落 → 6 子场景 / 35 镜（L01-L35）
- **输出模式**：**声画版**（画面版扩展 · 声音叙事融入 △）
- **视觉总纲**：2004-2006，**冷蓝（机房）→ 白炽（活动室）→ 暖黄（大排档）**；饱和度由低走高——本段是"颜色慢慢返嚟"的一段
- **模拟摄影机 / 胶片**：35mm（日 250D / 夜 500T），颗粒中低，黑位略抬；宵夜场暖部略提
- **画幅 / 帧率 / 快门**：**竖屏 9:16** / 24fps / 快门 180°
- **景深 / 焦点策略**：浅景深为主；初见场用**人群抽焦**（嘈杂中一眼锁住她）；可乐场用**玻璃反光 + 水珠微距**
- **光色 / 调色**：活动室白炽+窗外荔枝林绿（初见）→ 机房冷蓝（默契）→ 大排档暖黄但虚焦（醉酒）→ 自习室午后光柱（**全段最亮一束**，可乐场）→ 操场傍晚橙 → 宵夜暖黄+蒸汽（最暖）→ 收束降饱和
- **运镜基线**：定机 + 缓摇为主；L-4 可乐场**几乎全定机**（"砰"是唯一的"响"，镜头越静越衬）；L-5 蒙太奇用重复动作切
- **声音基线**：环境声基调=键盘"哒哒"/ 风扇"嗡嗡" / 饭堂嘈杂 / 操场脚步与风 / 大排档镬气+蒸汽嘶声；**情绪声音锚点 = 玻璃樽可乐"砰"（本段声音主角，出现两次：L22 落台大砰、L32 收束轻碰"叩"）**；声画关系=**L22 可乐"砰"先入（J-cut）——声先到，人后到**；**声音禁忌：不写配乐/BGM/具体曲目**

〔机位 A·POV〕
△**【竖屏 9:16 · 垂直画幅】**2004 年春，培正学院架空层长廊尽头，活动室门口。**竖构图：手写招新海报在上、我推门只手在下**。海报手写字："编程兴趣小组 · 招新"（泛光，不出校徽真貌）。入面白炽灯，一排电脑，七八个人围住中间一块萤幕。

〔机位 A·POV · 抽焦〕
△我的视线扫过入面——**一片人影都係模糊嘅**——突然**抽焦锁死喺一个位**：齐耳短发、发尾微外翘，着宽松黑 T 恤嘅女生，正指住萤幕讲嘢。**人群声一下子退远。**

〔机位 B·OTS〕
△从我肩后，望住佢——语速快、句子短：
> **林佳**："唔系数据嘅问题。系你个 loop 写反咗。"
> 被点嘅男生挠头。佢手指敲两下萤幕："睇呢度。你个 if 永远行唔到嚟。"

〔机位 C·细节〕
△**【竖屏 9:16 · 特写】**佢只手——指节利落，敲萤幕两下，停。萤幕泛光（代码唔出可读字）。旁边台面：一叠打印代码 + 一支黑笔（**林佳视觉锚**）。

△我坐低后排。佢扫过嚟一眼——**一秒**——转返去。我低头，扮睇书（**英文书**——细节：英文专业嘅人，坐喺编程兴趣小组）。
