# 《李富贵》分镜镜头脚本 · 爷爷灵前学医誓言段（粤语版）· AI 短剧

> 源文本：李富贵自传"真正的裂痕·第一次大力"段落
> 人物：李富贵（13 岁·初二）、李富财（13 岁）、爷爷（老钳工，已逝）、父亲（船上工程师）、叔叔，及"四大财子"其余三人（李栋雄/冯威捷/薛致远）
> 语言：全篇粤语对白 + 粤语旁白
> 时代锚定：90s 广州（约 1998-1999，初二）
> 情感基调：**克制、冷、不煽情**（贴合原文"快得像夏天的雷阵雨""脸上是空的""没有对视"）
> AI 短剧适配：竖屏 9:16 · 35mm 胶片 · 全段无 IP，无版权风险

## 【制作基线】

- **源剧本版本**：李富贵叙事文本（爷爷灵前学医段）
- **转换范围**：单段落 → 9 子场景 / 29 镜头（含 3-1b 医生宣告插镜 06a/06b/06c）
- **输出模式**：画面版（分镜镜头脚本，AI 短剧向）
- **视觉总纲**：90s 广州市井，冷色降饱和，"快→静→冷→微暖→沉"的情绪曲线
- **模拟摄影机 / 胶片**：35mm（日 250D / 夜 500T），颗粒中低，黑位略抬；棋摊戏偏暖（回忆前段），灵堂戏偏冷（白/灰）
- **镜头组 / 等效焦段**：棋摊 50mm；医院走廊 35mm 广角（拉长空间=茫然）；灵堂 50mm + 特写；走路 40mm 跟；题海 85mm 浅焦
- **画幅 / 帧率**：竖屏 9:16 / 24fps / 快门 180°
- **景深**：灵堂浅景深 F2.0；题海 F1.8 浅焦
- **光色 / 调色**：棋摊暖 → 医院冷白 → 灵堂冷灰 → 长路微暖 → 题海台灯孤光（由暖转冷再回孤光）
- **运镜基线**：棋摊"快"（手持轻晃+切快，雷阵雨感）；灵堂极静（几乎不动机）；长路缓慢跟；题海缓慢推
- **声音基线**：只写叙事性环境声（棋摊蒲扇/收音机/棋子、医院吊针"嘀"、灵堂香火、长路脚步、台灯电流），**不写配乐/BGM**；爷爷倒下那场**声音骤然抽空**（雷阵雨式）
- **克制铁律**：父亲/叔叔"脸上是空的"→ 拍**空脸+靠墙**，不哭；灵堂发誓→**没有对视、各自低声**，不喊不哭；全段禁煽情滤镜/禁哭戏

## 一、画面版脚本（粤语 · △ 自然融合）

### 场景 3-1　楼下棋摊 · 爷爷倒下　日 / 外　【快·雷阵雨感】
人物：爷爷、棋友两三人、街坊

△中景。90s 广州巷子楼下棋摊，塑料矮凳围着老式象棋桌，蒲扇、搪瓷缸、老收音机。爷爷（银白板寸、粗大指节）落子。

△快切。爷爷落子的手停在半空，棋子"啪"掉下。他手扶住桌沿，身体往前倾——（**动作快、不拖**）

△特写，爷爷额头一层汗，手从桌沿滑开，整个人朝下歪。

△全景（快），棋友扑上去扶，街坊围拢，有人喊"快叫车"。（节奏快得像夏天的雷阵雨，**声音在这一下被抽空半拍**）

△特写，棋盘上那枚没下的棋子，孤零零躺在格子里。（留 1 拍）

旁白（粤语，男声，中年回望，平）：
> 真正将我哋同富财推向唔同轨道嘅第一次大力，系喺我哋十三岁，初二嗰年。爷爷系突发心梗倒咗，喺楼下嘅棋摊上面。送去医院，冇救返过来。整个过程，快得咁，好似夏天嘅雷阵雨。

### 场景 3-1b　医院 · 病房门口 · 医生宣告　日 / 内　【冷·克制·插镜】
人物：医生（年长男医生·白大褂）、父亲、叔叔（病房门口）

△中景，90s 医院抢救室/病房门帘后，医生（年长、白大褂、摘下口罩，神情疲惫而克制）缓步走出。冷白走廊，日光灯"咝"，吊针"嘀嘀"在背景。

△近景，医生对画面外的父亲叔叔低声（粤语，平，不煽）：
> 我哋已经尽力咗。但系……人，冇救返。

△近景，父亲（消瘦、图纸手微颤）抬头，**脸上是空的**（不哭）；叔叔手一抖，攥住搪瓷缸，低低"嗯"咗一声。

△特写，医生转身返入病房，白大褂背影，门帘"沙"一声落下。（**克制收，不拖、不哀乐**）

（→ 接原场景 3-2：两人瘫靠病房外冰凉嘅墙。）

---

### 场景 3-2　医院 · 走廊 / 病房外　日 / 内　【冷·茫然】
人物：父亲、叔叔、（画面外：医生脚步/家属）

△全景，90s 医院，白色瓷砖走廊，日光灯冷白，吊针"嘀嘀"，空旷。

△中景，父亲（消瘦、图纸手微颤）同叔叔（年长些，同样身形）靠喺病房外冰凉的墙上，两人并排坐着，头微垂，**脸上是空的**（不哭、不喊，纯粹的茫然/无助）。

△特写，父亲一只手垂住，指节因画图弯曲、微颤，摊喺膝盖上，没有动作。

△特写，墙上日光灯"咝"一声，两人影子投喺瓷砖上，晃了一下。

旁白（粤语，平）：
> 父亲同叔叔，就好似两尊被抽咗走骨头嘅泥塑，靠住医院冰凉嘅墙。脸上系空嘅，一种面对不可抗力时，纯粹嘅茫然同无助。

### 场景 3-3　医院 · 走廊一角　日 / 内　【誓言起点】
人物：李富贵（13 岁）、李富财（13 岁）

△中景，走廊尽头，富贵同富财并肩站喺墙角，背靠冷白瓷砖，两个少年身形单薄。

△近景，两人望向病房门（画面外，门内透出医生/家属模糊脚步），都没有说话。

△特写，富贵手插喺裤袋，指节偏细；富财手指捏紧裤缝（两人各自动作，无对视）。

旁白（粤语）：
> 屋企冇人学医。就喺嗰一刻，"医学"呢个词汇，带住一种神圣嘅、可望而不可即嘅救赎光芒，同时击中咗我同富财。

### 场景 3-4　灵堂 · 蒲团　夜 / 内　【最静·核心】
人物：李富贵、李富财（并跪，画面内只见背影/侧）

△全景，灵堂。白幡、素色遗像（**遗像只拍轮廓+一束顶光，不做可辨认真人脸**）、香炉青烟、蒲团。冷灰调。

△中景，富贵同富财跪喺蒲团上，背对观众，隔住一只香炉，**没有对视**（两人各自朝向遗像，中间留空隙）。

△特写，香炉青烟袅袅，打喺两人之间，隔开又连上。

△近景，富贵侧脸（逆光冷），低声（**不抬头、不喊**）：
> 我要学医。
△近景，富财侧脸（另角度），几乎同时，低声：
> 我要学医。
（两句叠喺一起，冷空气中，**不加重音、不哭**）

△特写，两人指尖碰住（隔得极近），都没抬头。

旁白（粤语，平，收住）：
> 喺爷爷嘅灵堂前面，我哋两个跪喺蒲团上面，冇对视，却几乎同时，喺冰冷嘅空气入面，发咗同一个愿——我要学医。

### 场景 3-5　放学后 · 很长一段路　黄昏 / 外　【微暖·陪伴】
人物：李富贵、李栋雄、冯威捷、薛致远（"四大财子"陪着走）

△全景，90s 广州放学路（巷子/河堤/旧马路），四个少年行喺一条长长嘅路上，富贵喺中间，三人默默陪住，**不嬉闹、不话多**。

△中景，四人并排/前后，脚声踩喺旧路面，夕阳把四人影子拉得好长（呼应前段操场夕阳，但更沉）。

△近景，冯威捷欲开口，看看低着头的富贵，把话咽返（克制：没有再嬉闹）。

△特写，富贵背影，肩线平，走得很慢。

旁白（粤语，平中带一丝暖）：
> "四大财子"嘅另外三人，陪住我度过咗嗰段低沉嘅日子。我哋冇再嬉闹，只系喺放学之后，默默陪我行很长嘅路。嗰一刻嘅誓言，好似一颗沉重嘅种子，埋咗入心入面。

---

### 场景 3-6　题海 · 教室 / 台灯下　夜 / 内　【并肩·沉】
人物：李富贵、李富财

△中景，90s 中学教室放学后，只剩一排课桌，台灯孤光，窗外全黑，只有远处市井零星灯。

△近景，富贵同富财并排伏喺各自课桌做练习，台灯各照一面，**没有交流，各自埋头**（"同盟军"却各走各的题海）。

△特写，富财数学本（张数多），富贵语文/物理本（厚），两本摊喺桌面，隔着台灯。

△缓慢推近，两人影子在墙上并住又分开，台灯电流"咝"。

旁白（粤语，平，带重量）：
> 自此之后，我同富财嘅比较，有咗一个悲壮而同属一个嘅目标：市里面最好嘅中学，然后，系最顶尖嘅医学院。我哋再唔止系名字嘅比较，而系背负住同一句誓言嘅同盟军，喺题海入面并肩跋涉。

## 三、AI 分镜生成说明（喂 Kling / Sora / 可灵 / Seedance）

1. **逐镜成段**：把"画面 + 粤语旁白/台词 + 声音 + AI 关键词"拼一段，逐镜生成再按镜号拼接。
1.5. **⭐旁白粤语锁定（pavo-ai 内置 TTS · 防普腔 · 本段必带）**：
   - **根因**：pavo-ai 等工具内置旁白 TTS **默认按普通话读**——旁白文本虽是粤语口语，也会被读成普通话腔。**语言锁定必须直接写进提示词本身**。
   - **执行**：每镜拼段时，旁白文本前**永远紧跟一行语言锁定（中英都写）**：
     `旁白为粤语（广东话 / Cantonese / Yue Chinese）男声画外音朗读（中年回望，平，克制），禁止普通话（NOT Mandarin），保留粤语口癖（嘅/咗/唔/㗎）；旁白属画外音 VO，画面中人物不张嘴、不配台词。`
   - 若工具旁白/语音设置里有语种选项，**一律选 粤语 / Yue / Cantonese**，不得选 普通话 / Mandarin / CN。
2. **克制铁律（最关键，防 AI 过度煽情）**：
   - 爷爷倒下（镜 2-5）：**节奏快、声音抽真空**，不做慢镜头哀乐感；街坊"快叫车啦"是唯一的喊，且平。
   - 医生宣告（镜 06a/06b/06c，插镜）：医生**神情疲惫克制、低声、平**，"人，冇救返"一句**不加重音、不哀乐**；父亲叔叔**空脸不哭**（叔叔手抖攥搪瓷缸是唯一身体反应，微、克制）；门帘"沙"一声落下收，**不拖**。
   - 父亲叔叔（镜 7）：**拍"空脸+靠墙"，禁哭**——茫然比悲伤更冷更狠。
   - 灵堂发誓（镜 16-18）：**两人不抬头、不对视、不加重音**，"我要学医"是低声；指尖轻碰是全场唯一肢体亲密，别放大成抱/哭。
   - 全段**禁煽情滤镜、禁 BGM、禁泪特写**。
3. **遗像规避**：灵堂遗像只拍"素色轮廓 + 一束顶光"，**不生成可辨认真人脸**（避免 AI 乱画逝者脸）。
4. **两少年一致性**：富贵（13 岁·瘦削·单眼皮沉静·微侧分短发·抿嘴）、富财（同脸镜像·眼睛更亮·更舒展），沿用已锁定少年参考脸。
5. **情绪曲线**（调色按这个走）：棋摊暖 → 医院冷白 → 灵堂冷灰（最静）→ 长路微暖 → 题台灯台孤光（冷收）。
6. **粤语字幕**：普通话观众加"粤语+普通话译字"双字幕；"我要学医"叠音（镜 16/17）可同屏双字幕或并轨。
