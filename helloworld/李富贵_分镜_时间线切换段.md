## 【制作基线】

- **源剧本版本**：李富贵叙事文本（时间过渡段，补做）
- **转换范围**：时间转场段 → 6 子场景 / 20 镜头（第一人称 POV）
- **输出模式**：画面版 · 时间跳切蒙太奇（AI 短剧向）
- **视觉总纲**：广州，**冷（90s 高中）→ 快切（时间流逝）→ 暖（2003 城市一新）**；用"抽焦 + 定轴旋转（whip pan）+ 快切"承载时间跳变
- **模拟摄影机 / 胶片**：35mm（日 250D），颗粒中低，黑位略抬
- **画幅 / 帧率 / 快门**：竖屏 9:16 / 24fps / 快门 180°；**快切蒙太奇段允许 24fps 内 1-2 秒硬切**（时间加速感），不用升格
- **景深 / 焦点**：主浅焦 + **抽焦（rack focus）**；时间流逝用"抽焦 + 模糊硬切"
- **光色 / 调色**：90s 偏冷（承接高中段）→ 转场段微暖过渡 → 2003 落点最暖（"城市喺我眼前面变新"）
- **运镜基线**：90s 段定机/主观 → 转场 **whip pan（定轴旋转甩）** + 快切 → 2003 缓推

### 🔒 视觉规格偏离声明（时间蒙太奇 · 获准偏离）
- **偏离项**：本段为**时间流逝蒙太奇**，快切密度高于常规分镜（单场 3-5 个 1-2s 硬切），并含 **whip pan 甩镜转场**。
- **偏离原因**：表达"时间喺眼前一层一层流过、广州 90s → 2003 城市变新"的跳切效果（用户要求"时间切换到 2003 年这样的效果"）。
- **影响范围**：仅本转场段；快切段声音用"报时/翻历/城市白噪"叠压。
- **回归基线位置**：段末 T-6 **2003 定格空镜**回基线（缓推、静），不做快切。

### 🔒 独白层（第一人称当下）
- 内心独白为**富贵当下体验式第一人称**（"我记得嗰阵…""后来…""2003 年，我站喺广州"），粤语男声，口吻"身处其中"，不做抽离回望。

## 三、AI 分镜生成说明（喂 Kling / Sora / 可灵 / Seedance · 转场版）

1. **逐镜成段**：把"画面 + 视角 + 年代标记 + 粤语独白 + 声音 + AI 关键词"拼一段，逐镜生成再拼接；快切蒙太奇（T03-T08）可做成**一组连贯快切**一次出，再按镜号切。

1.4. **⭐旁白粤语锁定（pavo-ai 内置 TTS · 防普腔 · 本段必带）**：
   - **根因**：pavo-ai 等工具内置旁白 TTS **默认按普通话读**——独白文本虽是粤语口语，也会被读成普通话腔。**语言锁定必须直接写进提示词本身**。
   - **执行**：每镜拼段时，独白文本前**永远紧跟一行语言锁定（中英都写）**：
     `旁白为粤语（广东话 / Cantonese / Yue Chinese）男声画外音朗读（第一人称·当下口吻），禁止普通话（NOT Mandarin），保留粤语口癖（嘅/咗/唔/㗎）；旁白属画外音 VO，画面中人物不张嘴、不配台词。`
   - 若工具旁白/语音设置里有语种选项，**一律选 粤语 / Yue / Cantonese**，不得选 普通话 / Mandarin / CN。

1.5. **★竖屏 9:16 铁律（本段最高优先，防出横屏）**：
   - **根因**：出横屏是因为"竖屏"只写在文档【制作基线】，**每条分镜文本里没写**——AI 读单条分镜，看不到基线，就按默认横屏渲染。所以**每条分镜必须自带"竖屏 9:16 / 垂直画幅"字样**，不能只靠头部基线。
   - **构图转换（横屏思维 → 竖屏思维）**：
     | 横屏写法（会出横图） | 竖屏改成 |
     |---|---|
     | 远景，塔吊 + 新 CBD + 城市天际线（横向铺开） | **低角度仰拍**，塔吊/楼体**向上延伸占满画框**，天空在上、地面/身影在下 |
     | 两人并排走，横向铺 | **前后纵深**：我前景（背影/肩），她后景 |
     | 桌面物件横向摆 | **上下分层**：手/物件在下，环境在上 |
     | 甩镜横向摇 | **纵向定轴甩**（以画面中心为轴上下甩） |
   - **生成工具里同步锁**：① "本镜头场景设定"选**竖屏模板**（截图里那个 `Select` 是空的，先选上）；② 批量生成前比例选 **9:16**（不是默认 16:9）；③ 已生成的横屏图**删掉重生成**（已按横屏渲染死，改不了）。
   - **推荐在每条提示词开头固定加**：`竖屏 9:16，垂直画幅，手机竖屏构图，主体居中竖向，上下留白`。

2. **年代跳切效果（本段核心，防翻车）**：
   - **同机位换年代**（T06/T07/T09/T10）：构图/机位/焦距**完全不变**，只把"物件"（BP→手机、卡带→CD、无盖公交→空调公交）和"年代特征"换掉——这是做"时间流逝"最稳的手法，AI 不会漂。
   - **whip pan 定轴甩镜**（T05/T12）：用一个"甩镜模糊"盖住年代跳切（90s→2003），观众唔觉突兀；甩镜落定即 2003。
   - **抽焦 + 模糊硬切**（T03）：时间流逝段用焦点抽散 + 硬切，不要全程实焦。

3. **广州时代特征铁律（最重要，防错年代）**：
   - **广州塔（小蛮腰）= 2010 才建，90s 和 2003 一律不得出现**。2003 的珠江新城用"**在建工地 + 塔吊 + 旧村**"表达，不出现已建成的双子塔。
   - 90s：BP 机 / 卡带随身听 / 无盖绿涂公交 / 西关骑楼 / CRT 彩电。
   - 2003：翻盖手机（**不出可辨认品牌 logo**）/ CD 或早期 MP3 / 空调公交 / 地铁报站（1 号线 1998 已通车）。
   - 手机品牌、电视台台标都**只拍泛光轮廓**，不出可辨认 logo。

4. **POV 主观 + 闪回**（T15）：2003 段里插 0.5s **90s 亭娜侧脸闪回**（抽焦模糊），做"最明媚"回忆锚点；闪回要快、要虚，别抢主视角。

5. **亭娜一致性（保留）**：闪回亭娜沿用已定角色卡（马尾/侧脸绒毛/眼亮），先出正脸参考图；本段她只在 T15 闪回出现，不出新造型。

6. **声音（时间感）**：报时"噔"、翻历"沙"、BP"嘟"、划镜"嗡"、地铁报站——**声音先入/后出（J/L-cut）**做场间衔接；快切段城市白噪叠压，段末 T18/T19 **抽真空只留白噪**收（回基线）。**不写 BGM / 不出具体音乐曲目。**

7. **情绪曲线**：90s（冷，接高中段）→ 快切转场（中性偏暖过渡）→ 2003（最暖"城市一新"，但带一点"想打畀边个"的空）→ 缓拉收（为下段大学/进公司留接口）。

8. **粤语字幕**：内心独白第一人称当下口吻；普通话观众加"粤语 + 普通话译字"双字幕轨。
