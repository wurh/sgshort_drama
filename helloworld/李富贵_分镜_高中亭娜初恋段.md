## 【制作基线】

- **源剧本版本**：李富贵叙事文本（高中亭娜初恋段）
- **转换范围**：单段落 → 8 子场景 / 强化版镜头（含多机位）
- **输出模式**：画面版（分镜镜头脚本，AI 短剧向）· **第一人称 POV 强化**
- **视觉总纲**：90s 末-00s 初 广州，从冷（分岔/题海）回暖到最明媚（吻/秘密花园）
- **模拟摄影机 / 胶片**：35mm（日 250D / 夜 500T），颗粒中低，黑位略抬；前半偏冷，后半偏暖
- **画幅 / 帧率 / 快门**：竖屏 9:16 / 24fps / 快门 180°
- **景深 / 焦点策略（强化）**：全段主用**浅景深 + 抽焦（rack focus）**——"对焦从前景（卷堆/手/走廊）转移到亭娜"，表现"眼里只剩她"；吻戏 F1.8 背景灯光虚成光斑
- **光色 / 调色**：分岔/题海冷（承接上段台灯孤光）→ 辩论赛起回暖 → 操场/星空最暖最明
- **运镜基线**：题海压抑（广角主观+微晃）；辩论赛抽焦缓推；牵手主观手部入画；吻几乎定机（"时间仿佛停了"）

### 🔒 视觉规格偏离声明（主观视角 · 获准偏离）
- **偏离项**：本段以**第一人称主观视角（POV）为主叙事视角**，亭娜多以"富贵看她的角度"入画。
- **偏离原因**：原文为自传第一人称，POV + 当下体验独白能强化"代入富贵此刻的心动/紧张/克制"的情感沉浸（用户要求"第一人称拍摄，更深入情感"）。
- **影响范围**：全段镜头语言以"富贵视角"组织（POV / 过肩 OTS / 反打 / 主观特写），亭娜多为他视角中的对象。
- **回归基线位置（呼吸点，防 POV 疲劳）**：每场末尾 1 个**客观空镜/远景**回基线；**吻戏（4-6）结尾定机空镜**回基线；**4-8 结尾整段客观远景**收。POV 不贯穿到底，留"呼吸"。

### 🔒 独白层强化（体验式第一人称）
- 独白由"中年男声·回望讲述"改为"**富贵当下·体验式第一人称独白**"（"我看见她""我的心跳""我不敢松开"），仍粤语男声，口吻从"抽离回忆"变"身处其中"，以深入情感。
- 亭娜/富贵**对白保留原意**，不做改变。

## 【视角系统】（本版核心）

- **主视角**：李富贵第一人称（POV）。观众 = 富贵的眼睛 + 他的内心。
- **机位库（每戏可单选/拼接）**：
  - **A·POV 主观**：直接拍"富贵看到的"（她、他的手入画、光斑）。
  - **B·过肩 OTS**：从富贵肩/背后看她（有富贵在画框一角，代入又留客观）。
  - **C·反打 / 细节**：亭娜正面反打 / 两只手 / 卷堆 / 灯等细节。
  - **D·空镜（呼吸点）**：客观全景/远景/静物，回基线。
- **抽焦（rack focus）**：本段标志性手法——前前景失焦（卷堆/手/走廊），焦点滑到她脸上，表现"眼里只剩她"。
- **光斑入眼**：吻戏她眼里的教学楼灯光虚成光斑（他看她眼睛的特写）。
- **定机抽真空**：吻落时"时间仿佛停"——镜头定住 + 声音抽真空（只留呼吸/心跳）。
- **声音错位（J/L-cut）**：声音先入/后出做场间衔接；沉默用环境声反衬（不写"一片沉默"）。

## 三、AI 分镜生成说明（喂 Kling / Sora / 可灵 / Seedance · 强化版）

1. **逐镜成段**：把"画面 + 视角 + 粤语独白/台词 + 声音 + AI 关键词"拼一段，逐镜生成再按镜号拼接；多机位镜（同戏〔A〕〔B〕〔C〕）可**各出一版再择优**，或拍时**多机位实拍同拼**。

1.5. **⭐旁白粤语锁定（pavo-ai 内置 TTS · 防普腔 · 本段必带）**：
   - **根因**：pavo-ai 等工具内置旁白 TTS **默认按普通话读**——内心独白文本虽是粤语口语，也会被读成普通话腔。**语言锁定必须直接写进提示词本身**（给外部 TTS MP3 的工作流在 pavo-ai 上不适用）。
   - **执行**：每镜拼段时，内心独白文本前**永远紧跟一行语言锁定（中英都写）**：
     `旁白为粤语（广东话 / Cantonese / Yue Chinese）男声画外音朗读（第一人称·当下口吻），禁止普通话（NOT Mandarin），保留粤语口癖（嘅/咗/唔/㗎）；旁白属画外音 VO，画面中人物不张嘴、不配台词。`
   - 角色对白（亭娜/富贵）同样加锁：`人物对白为粤语（Cantonese / Yue Chinese），禁止普通话（NOT Mandarin），口型为粤语发音。`
   - 若工具旁白/语音设置里有语种选项，**一律选 粤语 / Yue / Cantonese**，不得选 普通话 / Mandarin / CN。

2. **POV 主观镜头（强化核心，防翻车）**：
   - 第一人称 POV = "**富贵看到的**"：他看亭娜（她入画）、**他的手伸入画**（牵手镜 17）、她**靠过来入画**（镜 26）、他**朝前凑近**（吻镜 22）。生成时务必让"富贵本人的手/视线"入画，做出主观代入感。
   - **过肩 OTS**：富贵肩/后脑入画一角，前景是他、焦点是她（镜 02/10/16）——既代入又留客观。
   - **避免**：POV 镜头不要出现富贵自己正脸（他是"看的人"，不是"被看的人"）。

3. **抽焦（rack focus · 本段标志性手法）**：
   - 镜 07：卷堆失焦 → 门口/窗外（声音先入 J-cut）。
   - 镜 08：**前景辩词/手失焦 → 焦点滑到亭娜脸**（"眼里只剩她"，最典型）。
   - 镜 18：她手 → 我出汗指节。
   - 生成时标清"前前景失焦 / 焦点在哪 / 抽焦方向"，避免 AI 全程实焦。

4. **光斑入眼 + 定机抽真空（吻戏爆点·镜 20-24）**：她眼里的教学楼灯光**虚成光斑**；吻落时**定机 + 声音抽真空（只留呼吸/心跳）**，"时间仿佛停"。**禁夸张亲热**，要"轻轻印落、随即闭眼静住"。

5. **多机位拼接原则**：同一戏〔A〕〔B〕〔C〕出多版后，按"主观代入为主、客观呼吸点收"的顺序剪；**每场末尾〔D〕空镜**回客观基线，防 POV 疲劳（回归基线位置已在偏离声明锁死）。

6. **音乐 IP 规避（保留）**：镜 25/26 卡带机/耳机，**勿生成可辨认 Beyond / 王菲 专辑封面或歌手脸**；统一"卡带机泛光 + 磁带缓缓转 + 两人各挂一只分线耳机 + 泛光打脸"，Beyond/王菲 交给台词点出。

7. **亭娜一致性（保留）**：马尾辫 + 碎刘海、侧脸下午绒毛、眼睛亮——每次出场锁死这三点（沿用已定角色卡，先出正脸参考图）。

8. **情绪曲线（调色按此走）**：分岔/题海（冷）→ 辩论赛抽焦眼亮（回暖）→ 同路（暖）→ 牵手主观手部（更暖）→ 吻光斑入眼（最暖·爆点）→ 秘密花园（最明媚）→ 结尾〔D〕客观远景微降（埋高考冷钩）。
   - ⚠️ **本段是全片"最明媚"的最高点**——按后文设定，**亭娜毕业后随父赴美**（非考去北京），因此本段所有"将来一定会有个位交集"的甜，结局是**跨洋的错位**。拍的时候**不加任何暗示性冷镜**（保持当下的纯净），把"后来断在太平洋两岸"留给下一段（高考崩塌·机场送亭娜）去完成急坠——**越干净，反噬越重**。

9. **克制铁律（保留）**：全段甜但不腻，吻戏"生涩克制"，不写 BGM、不放大亲热；沉默用环境声反衬（不写"一片沉默"，写"只剩虫声/远处市声"）。

10. **粤语字幕（强化）**：内心独白为**第一人称当下口吻**（区别于原"回望讲述"）；普通话观众加"粤语 + 普通话译字"双字幕轨。
