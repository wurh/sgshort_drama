## 【制作基线】

- **景深 / 焦点策略**：全段主用**浅景深 + 长焦静观**（人与世界的距离感）；机房场用**萤幕光打在脸上的单点照明**；图书馆场用**书架纵深 + 抽焦**

## 【粤语口语基准】（本段强制，防"普腔"）

> **铁律**：旁白/独白必须是**真粤语口语骨架**，不能是"普通话句子 + 贴上嘅/咗/唔"。对比：
> - ❌ 普腔："我投入到学习中，感到一种宁静" → ✅ 粤语："我匿埋喺图书馆，个脑终于静咗"

> - ❌ 普腔："代码让我感到确定性" → ✅ 粤语："代码就系咁——啱就系啱，错就系错"
> - 高频粤语词：匿埋/避埋/拾到/整日/睇下/谂返/点解/冇人/自己一个/静英英/做完就算

〔机位 B·OTS〕
△从我肩后，睇住父母帮我搬行李上宿舍楼。父亲行前面，背脊汗湿咗一片；母亲一路拨扇。我拖住个喼，跟喺最后面。楼梯系水泥嘅，一级一级，**每上一级，后面嘅声音就细一分**。到二楼转角，我**停低一步，回头望落去**——下面嘅人仲喺度嘈，我转返头，继续上。

### 场景 U-4　计算机入门教材 · 对就是对，错就是错　夜 / 内　【转折·蓝】

△**【竖屏 9:16 · 垂直画幅 · 萤幕单点光】**2003 年冬，宿舍夜。**竖构图：床架喺上、我张台喺下、成个画面净系得一盏光**。灯熄咗，只剩台上一部**厚背 CRT 显示器**发出冷冷嘅蓝光，照到我半张脸（**只出半边轮廓，唔出正脸**）。风扇"嗡嗡"，室友上面打呼。

△台角摆住一本**《C 语言程序设计》**（封面泛光），书角已经卷咗。我伸手翻到第一页，**用笔尖点住第一行**，一字一字读落去——读到一半，**笔尖停低**，我抬头，望住部黑住嘅萤幕，**睇咗三秒**，然后合书，跪低去床下，**扯出一堆线**：主机、键盘、拖板。我逐个插好，**指尖沾到灰，喺裤上抹咗一下**。

〔机位 C·细节〕
△**【竖屏 9:16 · 特写】**我按下主机电源。**风扇"嗡"一声起，萤幕"啪"一闪，亮起一片白**。萤幕上跳出黑底绿字嘅编译窗口，慢慢一行行滚落嚟。我翻开书，将书摆喺膝头，**左手一路按住书页，右手一 key 一 key 咁敲**——敲错一个字母，**退格三下**，再敲。

△手指敲落 `printf("Hello, World");`——**回车**。萤幕闪一闪，行出一行白字：`Hello, World`。

△我嘅手**离开键盘**。光标喺最后**一闪一闪**。

〔机位 A·POV〕
△我望住嗰行字，唔郁。**我嘅呼吸慢咗落嚟。** 蓝光喺我眼入面反一下。**我伸右手，指尖轻轻摸咗一下萤幕**——玻璃系暖嘅。

〔机位 B·OTS〕
△从我后脑勺嘅一角，望住萤幕上嗰行字。宿舍窗外，远处有一盏路灯，光好黄。**画面入面只有：我的后脑、我的肩、一块发蓝嘅萤幕。**

〔机位 C·细节〕
△**【竖屏 9:16 · 特写】**我把书尾嘅代码**改咗一个字**——弹返一个红色报错，成行字标红。**我删返，改返啱，回车——红变白，过咗。** 我又改，又报错，又改返。**同一个动作，我重複咗三次。** 第三次过嗰阵，我**轻轻"嗯"咗一声**。

△萤幕右下角嘅时钟跳：`02:47`。旁边一罐已经饮完嘅玻璃樽可乐，樽身凝住水珠，一滴落台面。

〔机位 D·空镜〕
△**【竖屏 9:16 · 定机】**整栋宿舍楼嘅外景，黑，只剩两格窗透住蓝光。风一吹，树影晃。

#### U-5-a　同一张书桌 · 同一块萤幕　夜 / 内

〔机位 A·POV · 固定机位〕
△**【竖屏 9:16 · 定机 · 同机位四切】**同一张书台、同一个角度、同一块萤幕、**同一只手伸入画**。**只换年代：**

- **2003**：厚背 CRT，萤幕鼓起，发出"滋——"嘅高频声；我嘅手**拍咗一下机身侧面**，画面雪花闪一闪；旁边一叠软驱盘。
- **2004**：我嘅手**翻开一部蓝色小屏嘅翻盖手机**，"啪"；萤幕换成薄身液晶；墙上多一张 QQ 群嘅打印纸。
- **2005**：我嘅手**刮开一块点卡**（魔兽世界，泛光）；旁边一罐空可乐；液晶上一页淘宝网首页（泛光，出唔清字）。
- **2006**：我嘅手**拉开一副头戴式耳机，戴上去**；台面多咗 MP3（千千静听）；萤幕开住魔兽世界登录界面（泛光）。

〔机位 C·细节〕
△**【竖屏 9:16 · 四次特写叠化】**同一位置嘅特写，四次，**全部由一只手完成动作**：

1. 2003：**软盘插入软驱**，"咔哒"，指示灯亮。
2. 2004：翻盖翻开，"啪"，小萤幕亮。
3. 2005：**指甲刮过点卡涂层**，细碎"沙沙"。
4. 2006：**耳机线拖过台面**，一只手将耳机扣上耳朵，肩头轻微一动（一串模糊嘅电子乐前奏，唔可以出曲名）。

> 独白（唯一一句，跨度）：个几年，成栋宿舍都喺度打机、淘嘢、开黑。净系我，仲系匿埋喺图书馆同机房。

#### U-5-b　同一条路 · 同一个角度　日 / 外

〔机位 A·POV · 固定机位〕
△**【竖屏 9:16 · 定机 · 低角度仰拍 · 同机位四切】**同一个校园路口，同一栋教学楼，同一角度向上望。**只换细节，唔换构图：**

- **2003**：公告栏贴**纸质海报**，**一只手撕走一张过期嘅**，边角畀风扯起。
- **2004**：公告栏多咗**彩色打印**海报；**一只手抽出一部 MP3**，耳机线垂低。
- **2005**：公告栏挤满**社团招新 + 网吧广告**；**行人低头睇手机**，一路行一路睇，撞到人都唔知。
- **2006**：公告栏换成**喷绘布**；路边多咗**LED 灯箱，天未黑就开始亮**，光打喺行人面上。

〔机位 D·空镜〕
△**【竖屏 9:16 · 定机缓摇】**图书馆外面嘅**荔枝林**，四年一个循环：绿 → 红（挂果）→ 落 → 又绿。同一棵树，同一条红砖小径，**四年间有人喺同一条径上行过、又唔见咗**。

△隔咗两秒，我**用食指将部手机推远啲**，推到台角，推咗一下，冇再郁。

〔机位 D·空镜〕
△**【竖屏 9:16 · 定机】**宿舍窗外，广州嘅夜，远处车流一条条光。**留白 3 秒。**

△我合埋个翻盖手机，"啪"。屏幕黑咗。宿舍黑咗。**净系剩风扇"嗡嗡"。** 我冇躺低，**就咁坐喺度，望住黑咗嘅萤幕**。

> 独白（唯一一句）：佢寄 email 讲，佢嗰边落雪。…我一封都冇回过。

〔机位 D·空镜 · 呼吸点〕

〔机位 A·POV〕
△我拧头睇一睇成排萤幕嘅蓝光——**同一款光，同四年前嗰晚一模一样**。我嘅手**摸咗一下自己个头**（短平头），然后返去键盘。

〔机位 D·空镜 · 客观远景 · 归基线〕
△**【竖屏 9:16 · 客观远景（首次脱离 POV）】**机房大楼外景，凌晨三点，一格一格嘅窗透住蓝光，**我喺倒数第二格，系一粒睇唔清嘅人影**。镜头上摇，露出 2006 年广州嘅夜空，远处**中信广场**嘅尖顶灯。

## 三、AI 分镜生成说明（喂 Kling / Sora / 可灵 / Seedance）

1. **竖屏 9:16 铁律**：每条分镜**自带"竖屏 9:16"字样**（别只靠头部基线）；构图**主体竖向居中、上下分层**，禁止横向铺开。工具里比例选 **9:16**，场景设定选**竖屏模板**；已出横屏的删掉重生成。

2. **第一人称 POV（本段核心）**：
   - **全段不出现富贵正脸**——他是"看的人"。用**我的手 / 我的键盘 / 我的视线 / 我的后脑勺一角**做代入。
   - 例外两处：U42（客观远景，我只是一粒人影）——这是**有意归基线**，用来"把我从画面里放出去"，作段落收束。
   - U-7 机房场用**一排萤幕的纵深透视**做"我坐在其中"的视觉证据，比拍脸更有效。

#### ★ 2.5　少旁白 · 演绎优先（本版修订铁律）

> **本版最大改动**：独白从"每镜都有"压缩为**全段仅 6 句**（U05 / U10 / U14 / U19 / U25 / U29 / U35 / U42 中的断言句），其余全靠**动作与画面叙事**。

**改写原则（三刀）**：
- **第一刀｜叙述性独白全删**：凡是"交代我做了什么"的句子一律砍掉（如"我开始成日匿埋喺图书馆""个几年我张台上面嘅嘢一路换"）→ 改为**让动作自己说**。
- **第二刀｜判断性独白保留（关键）**：凡是"我内心的判断/感受"留下的——因为**演不出来**（如"你对就对，错就错"）。这类是全段的情感内核，**删了会失重**。
- **第三刀｜动作加厚**：每删一句独白，就在同一镜**加回一个可见动作**。可加的动作为：
  - **手部**：摺通知书/推手机/摸萤幕/摸自己个头/抹灰
  - **视线**：停半秒/飘窗外/收回/跟手又收回
  - **身体**：肩膀垂落/靠后一靠/收手/坐住唔躺低
  - **微小反应**：顿笔/轻轻"嗯"/嘴角极轻微动

**对照示例（本段实际改写）**：

**执行提示（给 AI 生成）**：
- 校验一条分镜是否合格：**"把独白静音，观众还能不能看懂这一镜在讲什么？"** —— 能，才合格。
- 独白**只在动作完成后出现**（不是动作的前导），让它听起来像"事后的一口气"，不像"解说字幕"。
- 本段**独白总量目标 ≤ 60 字**（改前约 400+ 字）。若某镜必须靠独白才成立，说明动作没写够，回去补动作。

9.5. **⭐旁白粤语锁定（pavo-ai 内置 TTS · 防普腔 · 本段必带）**：
   - **根因**：pavo-ai 等工具内置旁白 TTS **默认按普通话读**——独白文本虽是真粤语口语，也会被读成普通话腔。在 pavo-ai 上**外部 TTS MP3 后期铺的工作流不适用**（平台内生成），**语言锁定必须直接写进提示词本身**。
   - **执行**：喂 pavo-ai 时，每条含独白的分镜提示词，独白文本前**永远紧跟一行语言锁定（中英都写）**：
     `旁白为粤语（广东话 / Cantonese / Yue Chinese）男声画外音朗读（第一人称·当下口吻），禁止普通话（NOT Mandarin），保留粤语口癖（嘅/咗/唔/㗎）；旁白属画外音 VO，画面中人物不张嘴、不配台词。`
   - 若平台生成设置里有旁白/语音语种选项，**一律选 粤语 / Yue / Cantonese**，不得选 普通话 / Mandarin / CN；生成后听一遍抽查 1-2 句，若仍为普通话腔，把锁定行加粗前置到提示词第一行再重生成。

10. **粤语字幕**：内心独白第一人称当下口吻；普通话观众加"粤语 + 普通话译字"双字幕轨。
