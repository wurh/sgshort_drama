# 《李富贵》分镜镜头脚本 · 童年比较段（粤语版）

> 源文本：李富贵自传"富贵/富财·童年比较"段落  
> 新增元素：童年动漫（《龙珠》《恐龙战队》《数码暴龙》）+ 90s 广州老式公交  
> 语言：全篇粤语对白 + 粤语旁白  
> 时代锚定：1985 年广州出生，本段落 = 约 1991-1999 小学期（90s 广州）  
> 视觉基调：90s 海珠区老屋/老巷子，现实主义克制调性，童年回忆略带暖色

---

## 【制作基线】

- **源剧本版本**：李富贵叙事文本（童年比较段）
- **转换范围**：单段落 → 6 个子场景 / 20 个镜头
- **输出模式**：画面版（分镜镜头脚本）
- **视觉总纲**：90s 广州海珠区老住宅+老巷子，市井烟火，克制不煽情
- **模拟摄影机 / 胶片**：35mm 胶片（Kodak Vision3 500T 夜 / 250D 日，或 Fuji 500T），颗粒中低，黑位略抬，肤色偏暖
- **镜头组 / 等效焦段**：中焦为主（50mm 等效），回忆戏 40-60mm；公交外景 35mm 广角
- **画幅 / 帧率**：竖屏 9:16 / 24fps（胶片感）/ 快门 180°
- **景深**：浅景深 F2.8，回忆戏边缘虚化
- **光色 / 调色**：暖色降饱和，中低颗粒，肤色保留真实
- **运镜基线**：回忆戏缓慢推/移，克制；公交戏稳定跟拍
- **声音基线**：只写叙事性环境声（老电车"叮"、市声、电视泛光里的动画片电子音效），**不写配乐/BGM**
- **版权规避**：动漫一律用"电视屏幕冷光 + 晃动剪影 + 光打在娃娃脸上"表达，**不直接生成有版权的动漫角色**；公交用"90s 广州无盖/老式公共汽车（铁皮车身、木扶手、绿涂装）"描述

## 一、画面版脚本（粤语 · △ 自然融合）

### 场景 1-1　李家门楣 · 老巷子　日 / 外

人物：旁白（李富贵）　〔画面无实人〕

△俯拍/低机位。90s 广州老巷子，骑楼连廊，晾衣杆上挂着汗衫。巷子尽头，一辆 90s 广州无盖老式公共汽车（铁皮车身、木扶手、绿涂装）缓缓驶过，车轮"吱呀"，报站"叮"一声。

△中景，巷子中段李家大门。门楣上并排贴着两串老式黑底红字门牌——"富贵""富财"，挨得齐齐整整，纸边微微泛黄起翘。

△特写，两串名字并排，"贵""财"两个字隔得极近，像连体。

旁白（粤语，男声，中年回望）：

> 富贵、富财。我哋两个，就好似一对被时代寄予厚望嘅连体标签，齐齐整整贴晒落李家第三代嘅门楣上面。

### 场景 1-2　同一条巷 · 上学路　日 / 外

人物：李富贵（6-10 岁）、李富财（6-10 岁）

△全景。两个背小书包、系红领巾嘅娃娃并排行巷子，晨光斜射，影子拉得老长，两个影子并排。

△中景，两人行路拌嘴，温和。  
富贵（粤语）：

> 今日数学考几何啦。  
> 富财（粤语）：  
> 语文我赢你。  
> 富贵（粤语，不接话，快走一步）：  
> 睇住先啦。

△特写，两人脚并排迈开，红领巾被风吹起。

旁白（粤语）：老式公交

> 同年，住紧同一条巷子，仲上紧同一所海珠区嘅重点小学。比较，从出世嗰一刻就开始了。

### 场景 1-3　教室 · 前三名　日 / 内

人物：李富贵、李富财、老师（背影/侧）

△中景。90s 小学教室，木课桌成排，吊扇打转，黑板上字还没擦。后墙贴住"流动红旗"同成绩榜。

△特写，老师粉笔喺成绩榜上划名次，第一格今日画"财"，第二格画"贵"，轮流转。

△近景，富贵同富财坐各自课桌，一个压住语文本，一个压住数学本，各睇各。

旁白（粤语）：

> 喺年级入面你追我赶，轮流转坐前三。佢数学脑瓜活，我语文底子稳。

### 场景 1-4　客厅 · 看动漫　夜 / 内　【新增】

人物：李富贵、李富财

△全景。90s 广州老屋客厅，竹椅、矮凳、茶几。一台黑色大屁股彩电，顶上插住八木天线，吊扇缓缓转。旁边一搪瓷杯、一碟爆米花。

△特写，电视屏幕泛起一片冷光（**不直接呈现动漫角色，只拍屏幕泛光 + 墙上投出晃动嘅彩色剪影**），冷光打在两张娃娃脸上，墙面影像忽大忽细。

△近景，两人抢住遥控器。  
富财（粤语，眼睛发亮）：

> 下集悟空要变超级赛亚人！你咪瞓啦！  
> 富贵（粤语，按停）：  
> 恐龙战队嗰个，红队先正过你。  
> 富财（粤语，拍爆米花碟）：  
> 数码兽！我哋个阿古兽最叻！  
> 富贵（粤语，不抬头）：  
> 得闲先讲，第一集仲未睇完。

△特写，两人眼睛映住电视泛光，专注。

旁白（粤语）：

> 嗰阵时最爱睇嘅，就系《龙珠》、《恐龙战队》、《数码暴龙》。一部都唔肯错过。

### 场景 1-5　放学 · 老式公交　日 / 外→内　【新增】

人物：李富贵、李富财、女售票员（90s）

△全景。90s 广州无盖/老式公共汽车靠站，铁皮车身、木扶手、绿涂装。报站"叮"一声，车门开。

△中景，两个娃娃挤上车，投币箱"叮当"一响，女售票员攞住票夹过来。

△近景，车窗外 90s 广州街景流动（骑楼、晾衣、老档口），车内木扶手晃动，两小孩抓着坐住/站住。

△特写，两人并排，一个靠住车窗，窗外街景流过，表情平静，竞争感淡咗。

旁白（粤语）：

> 放学返屋，挤同一部公交车。比较喺嗰阵，仲温和，仲带返亲昵嘅竞争意味。

### 场景 1-6　巷口 · 大人说笑　日 / 外（收束）

人物：长辈（大妗/叔叔）、李富贵

△中景，巷口/饭桌旁，两个长辈笑呵呵，粤语。  
长辈（粤语，笑）：

> 李家呢对宝贝，一文一武，将来都有出气嘅。

△近景，富贵喺旁听住，嘴角抿住（性格底色：不话甜言，抿嘴），唔接话。

△远景收，巷子、晾衣杆、天边 90s 夕阳，画面由暖逐渐降饱和，慢慢收。

旁白（粤语，收）：

> 喺好长一段日子入面，呢种比较，仲係温和嘅。

## 三、AI 分镜生成说明（喂给 Kling / Sora / 可灵 / Seedance）

1. **每镜独立成段**：把"画面内容 + 粤语旁白/台词 + 声音 + AI 提示关键词"拼成一段提示词，逐镜生成，再按镜号拼接。
1.5. **⭐旁白粤语锁定（pavo-ai 内置 TTS · 防普腔 · 本段必带）**：
   - **根因**：pavo-ai 等工具的内置旁白 TTS **默认按普通话读**——旁白文本虽是粤语口语，也会被读成普通话腔。"生成 TTS MP3 后期铺"的工作流在 pavo-ai 上不适用，**语言锁定必须直接写进提示词本身**。
   - **执行**：每镜拼段时，旁白文本前**永远紧跟一行语言锁定（中英都写）**：
     `旁白为粤语（广东话 / Cantonese / Yue Chinese）男声画外音朗读，禁止普通话（NOT Mandarin），粤语口癖（嘅/咗/唔/㗎）；旁白属旁白者本人（画外音 VO），画面中人物不张嘴、不配台词。`
   - 台词为角色对白时同样加锁：`人物对白为粤语（Cantonese / Yue Chinese），禁止普通话（NOT Mandarin），口型为粤语发音。`
   - 若工具旁白/语音设置里有语种选项，**一律选 粤语 / Yue / Cantonese**，不得选 普通话 / Mandarin / CN。
2. **动漫版权规避（关键）**：
   - 镜 11/12/13 的电视画面，**不要让 AI 直接生成《龙珠》《恐龙战队》《数码暴龙》的角色脸**（既有版权风险，AI 也难还原）。
   - 统一用：**"彩色电视屏幕泛起的冷光 + 墙上投出的晃动彩色剪影 + 光打在两张娃娃脸上"**，只保留"动画片在放"的氛围，不点具体角色。
   - 台词里提"悟空/红队/阿古兽"即可让观众明白是什么片，画面不用出角色。
3. **90s 广州公交**：统一描述为"**无盖/老式铁皮公共汽车，绿色涂装，木质扶手，车顶有吊杆/无盖**"，可参考广州老"无盖电车"造型；投币箱、女售票员持票夹、报站"叮"是年代锚点。
4. **粤语对白**：若目标平台是普通话观众，可加**粤语字幕 + 普通话译字**双字幕轨；台词本身保持粤语音色不翻译。
5. **两小孩一致性**：富贵 vs 富财 = 相似脸型镜像，但**富财眼睛高光更强、笑起来明显**（全片"命运分岔"的视觉隐喻），AI 生成时给两人分两张参考脸锁定。
