# 《美女丧尸艳遇》世界观设定（2065 穿越版 · 重写）
> 编剧：墨烨｜替代旧版"当代釜山怪象"设定。本文件是全剧母题与规则的唯一事实源。

## 一、时代背景
- 主角吴明（30 岁）是**丧尸剧重度爱好者**，一个人狂刷丧尸片当日常。
- 某天深夜，**一道闪电直接劈中他的老电视**，蓝光炸裂——吴明醒来，人已在 **2065 年的韩国**。
- 2065 年韩国 = 超级高科技都市：悬浮通勤、全息界面、AI 城市管理、生物升级技术普及。表面比吴明"来的那个世界"先进一大截。

## 二、核心设定：人类"升级"
- 这个时代，人类进行了生物升级，**升级主要发生在女性身上**。
- 升级后，女性可以在**「人类形态」与「丧尸形态」之间自由切换**。
- **全剧恐怖母题（悬念）**：外人**无法分辨**谁还是纯人类、谁已经"人尸混合"。
  - 一个冷艳、精致、优雅的都市女性，随时可能是**伪装成人类的丧尸猎手**。
  - 吴明（及观众）最大的恐惧 = "我根本分不清谁该信"。
- 女性丧尸一般在**夜间**活动，**诱杀并捕猎男性**（白天靠社会身份/科技伪装保护，夜晚回归本能）。
- 识别特征（吴明逐步总结出的"弱点"，供后续反杀）：畏强光、对高温/冲击敏感、切换形态时会有**下颌反折 / 皮下血管游走 / 妆容龟裂 / 瞳孔变青黑**等局部破绽。

## 三、主角
- **吴明**：丧尸剧狂爱好者，被雷击电视送到 2065 韩国。手握"看过上百部丧尸片"的经验直觉 + 现代人常识，却被扔进一个"科技碾压、规则全变"的陌生世界。
- 成长弧线：从"看客/旁观记录者" → 被裹挟成"猎物视角的幸存者" → 学会"观察-伪装-反向利用规则"主动破局。
- 视觉：30 岁东亚男性，偏瘦，面部硬朗，眼神锐利警惕；常穿略显廉价的休闲西装（与 2065 高科技形成"外来者"反差），挂运动相机记录。

## 四、基调与合规
- 基调：**生存恐怖 + 悬疑**（"谁是丧尸、谁是猎物"的猜忌）。聚焦"生存与猜忌"，**不渲染性别仇恨**（规避引战举报）。
- 性感 = 捕猎伪装（魅力陷阱），恐怖来自反差，**不写露骨性暗示/低俗台词**。
- 变异 = 局部特写 + 遮光 + 声音暗示（下颌反折/皮下血管/妆裂/瞳孔异变），**不堆 gore 血腥**。
- 进食/捕猎场景：按"猛兽处理猎物"逻辑写，用**远景/遮光/声音**表现，不写感官化、不写色情化。
