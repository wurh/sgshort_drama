# 《美女丧尸艳遇》第一人称 POV 拍摄规范（全剧统一 · 可复用）
> 编剧/导演：墨烨｜适用：全剧所有分镜（第1集起）｜类型：AI 视频生成 / 分镜执行
> 一句话铁律：**全片机位 = 吴明的双眼（或他佩戴的运动相机）。永不出现"别人拍吴明"的第三人称镜头。**

## 一、为什么第一人称
- 强化"记录者"母题：他手里那台**运动相机**本身就是 POV 装置，"红 REC 灯"是全片视觉签名。
- 强化"猜忌"恐怖：观众被迫和他一样"分不清谁是丧尸"——因为你也只能从他的眼睛看。
- 强化"被狩猎"代入：猎手"转头"= 朝镜头看 = 直接看进观众（吴明眼睛）里，惊悚度拉满。

## 二、双层 POV（核心装置）
| 层 | 机位 | 画面特征 | 用途 |
|---|---|---|---|
| 裸眼 POV（主） | 吴明双眼 | 视线随他蹲/弯腰/转身位移；手/相机入画 | 现实主体 |
| 相机 POV（副） | 胸前/头戴运动相机 | 广角偏鱼眼(16-17mm)、**HUD：REC红点+时间码+电池%**、轻微手持抖 | "取证/回放"时刻、关键证据 |
- 切换规则：现实=裸眼；吴明在"录像取证/回放/偷拍"=切相机POV（可加鱼眼+HUD）；两层可叠化转场。
- 相机 POV 是"画面里的画面"：可让关键画面（门缝窥视、被猎手转头）同时"被录下来"，埋"证据"伏笔。

## 三、吴明"露脸"的唯一合法方式
- 全片吴明的脸**不入画**（因为镜头就是他的眼睛）。
- 需要"他的脸"时，只用**反射/倒影**：终端玻璃、破碎玻璃、镜面、水杯、手机屏。
  常用手法：他低头/侧首，从一块反光里瞥见自己**苍白的脸**（恐惧时）——"他只能从倒影里看到自己"。

## 四、情绪与身体状态用 POV 表达（不靠拍脸）
| 状态 | POV 表达 |
|---|---|
| 心跳/紧张 | 心跳声放大 + 画面轻微呼吸式起伏 |
| 被吓僵 | 镜头骤停 + 死寂(环境音瞬间消失) |
| 头晕/失血 | 画面倾斜/边缘模糊、失焦再对焦(=他眨眼) |
| 奔跑 | 手持剧烈抖 + 呼吸/脚步 |
| 屏息躲藏 | 镜头压低贴地/贴墙 + 呼吸压到最低 |
| 他"说话" | 台词=画外气声(镜头是自身) + 内心独白=画外 OS |

## 五、"被猎手发现"的 POV 处理（本剧签名镜头）
- 猎手"转头" = **朝镜头/观众转头**（她正在看吴明=看你），停 1-2 帧再恢复，制造"被看见"。
- 高跟鞋声做 **360° 环绕声**（POV 里靠听声定位猎手方位）。
- 猎手逼近 = 她在视野里**朝镜头方向位移**（越走越近=越危险）。

## 六、打斗戏 POV 铁律
- 只出现**吴明自己的手/臂**（抓灭火器、挥肘时见自己手臂、护脸、扶框）。
- 对手永远"在画面里"，**自己的身体永不出画**。
- 受击反馈用 POV：气体/碎片/血雾**糊满镜头**（前景遮挡，规避 gore）；被打中=画面一晃/一黑 + 失衡倾斜。
- 每个招式拆多镜（15s 一镜一招），命中必有"镜头糊/晃/黑"反馈。

## 七、空间锚点（防 POV 迷路）
- 每个**新场景第一个 POV 镜头**先给"我在哪"：扫视头顶霓虹 / 低头看脚下 / 前方人群，建立方位再进剧情。
- 转场用"睁眼/闭眼(黑场)"或"低头-抬头"完成，不用硬切。

## 八、音画总则
- 环境声环绕为主（脚步声/高跟鞋/都市嗡鸣）。
- 吴明台词 = 内心 OS 画外音；他会说出口的话 = 画外气声（镜头是他自己）。
- 音效分层：环境声 / 叙事音效（下颌"咔"、心跳、高跟鞋骤停）/ 情绪声音（呼吸、心跳放大）。

## 九、15s 单镜铁律（沿用）
① 台词≤2短句；② 动作=单一招式/单一反应；③ 打戏按招式拆多镜；④ 每个新元素前一镜铺垫。

## 十、AI 视频提示要点（POV 专用）
- 每镜标注 POV 层（裸眼/相机）与 HUD（相机层）。
- "被看"镜头必写："丧尸转头朝镜头，直视观众，停1-2帧"。
- 反射露脸必写："从X反光里瞥见男主苍白侧脸"。
- 打斗前景必写："泡沫/碎片/血雾糊满镜头前景，遮挡主体"。
- 空间锚点必写："开场扫视，建立我在X的方位"。
