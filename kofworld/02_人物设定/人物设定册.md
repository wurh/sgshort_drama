# 《格斗家世界》人物设定册（第一季）

> 每个核心角色含：花名/全名、年龄外貌、性格底色、人物弧线、核心欲望与恐惧、标志性口头禅/行为习惯。
> 战力定位对齐《世界观与规则表》战力阶梯。

---

## 一、吴真（主角）

- **全名 / 花名**：吴真 / 圈内被叫"那个背招式的"、后称"预知者"
- **年龄外貌**：30 岁（穿越后外表不变），程序员身材——微驼、眼镜、T 恤牛仔裤；进入拳馆训练后体态渐挺拔，眼神从涣散变锐利。**标志性外形**：黑发（常乱翘）、一副黑框眼镜（关键道具，摘镜=认真时刻）、右手腕戴一条旧运动手环（家里人的遗物，情感锚点）。
- **性格底色**：表面是怂怂社畜，内心是"背了二十年 KOF"的硬核老玩家。冷静、计算型，把生活当"段位挑战"；骨子里有股不服输的狠劲（被羞辱时眼里会放光）。
- **人物弧线**：文弱社畜 → 94 年高人指点 → 信息差觉醒 → 惊艳全场 → 虽败犹荣 → 成为"改变历史的人"。
- **核心欲望**：表面是想回家；深层是"证明自己这辈子不只是个打游戏的，我是能改变世界的格斗家"。
- **核心恐惧**：金手指失灵 + 回不了家 + 介入越深历史越失控（"我越爽，世界越歪"）。
- **口头禅 / 习惯**：
  - 「我玩过的，就赢不了。」（自信时）
  - 「这一招，我见过一百次。」（出招前，信息差金手指的标志台词）
  - 紧张时会推眼镜；认真出招前会**摘眼镜**（仪式动作，镜头记忆点）。

---

## 二、董泉博士（引路人 / 关键配角）

- **全名**：董泉，时空物理学家，45-50 岁
- **外貌**：清瘦，白大褂（实验室场景），花白头，眼神锐利带疲惫，口袋常插着钢笔。
- **性格底色**：天才式的偏执，科学家的孤独。他造时光机不是为了好玩，是要"修补时间"。
- **人物弧线**：科技节上自信满满 → 时光机实验出意外 → 对吴真产生愧疚与"托付感"。
- **核心欲望**：修补时间锚，让意外者回家。
- **核心恐惧**：自己成为"时间失控"的源头。
- **口头禅**：「时间是可逆的……理论上。」（越到后面越心虚，成为悬疑伏笔）

---

## 三、草薙京（日本队 · 偶像 / 宿敌线）

- **全名**：草薙京，KOF 94 日本队代表，武术世家
- **外貌**：金发扎马尾，额前垂一缕，额饰带草薙火焰，白色武道服，神情桀骜。
- **性格底色**：天才+傲气，看似玩世不恭，实则极重承诺、极重对手。
- **人物弧线**：对吴真先"看不上"→ 交手后"刮目相看"→ 最终给主角认可与警示（"你身上有奇怪的东西"）。
- **核心欲望**：证明自己家传古武术的真正传人身份。
- **核心恐惧**：火焰的力量失控（草薙之火反噬自身，第二季伏笔）。
- **口头禅 / 习惯**：出招前轻笑「有意思。」；招牌必杀**百鬼夜行**前会甩发。

---

## 四、二阶堂红丸（日本队 · 兄弟情 / 热血）

- **全名**：二阶堂红丸，KOF 94 日本队，雷属性格斗家
- **外貌**：红发，蓝色背心短裤，肌肉线条硬朗，笑容阳光但眼神有狠劲。
- **性格底色**：热血、直接、护短，"打就完了"派。是第一个认可吴真的人（主角兄弟情锚点）。
- **人物弧线**：从看热闹 → 被主角的"计算型打法"折服 → 主动结盟。
- **核心欲望**：赢，然后"再来一次"，享受对决本身。
- **核心恐惧**：变强但交不到值得拼命的朋友。
- **口头禅 / 习惯**：「打就完了！」；出招前会甩袖子引电（**雷火**前摇动作，镜头记忆点）。

---

## 五、椎拳崇（日本队 · 巅峰 / 主角季末对手）

- **全名**：椎拳崇，KOF 94 日本队，气功系
- **外貌**：蓝发，紫色道服，戴护目镜，圆脸带憨笑，实则高手。
- **性格底色**：外表搞笑卖萌，实力深不可测；讲究"气"的境界。
- **人物弧线**：主角的"镜像对手"——主角靠信息差，他靠"气的直觉"，**两条路线的对决是本季最高潮**（主角虽败犹荣的高光战）。
- **核心欲望**：证明"气"比"招式"更强大。
- **核心恐惧**：自己只是被招式定义的人。
- **口头禅 / 习惯**：「来呀～！」；**龙卷飓风**前会原地转圈蓄气。

---

## 六、八神庵（反派线 / 杀意级 · 季末威慑）

- **全名**：八神庵，红发黑衣，"杀意"代名词
- **外貌**：红发，黑色皮衣，脸上三道疤，眼神冷冽。
- **性格底色**：孤狼，纯粹的战斗狂，"为打而打"，对强者有扭曲的尊重。
- **人物弧线**：本季仅作"阴影威慑"，不出拳也压场；给主角（和观众）"天花板"概念。
- **核心欲望**：一场"值得"的战斗。
- **核心恐惧**：失去战斗意义的空虚。
- **口头禅 / 习惯**：「来。」（一个字，最压迫感）；**无式焚天**前会闭眼蓄红焰。

---

## 七、吉斯·南镇（反派 Boss / 第二季主威胁 · 本季阴影）

- **全名**：吉斯·霍华德 / 南镇，操控格斗家大赛的幕后
- **外貌**：银发西装，永远微笑，优雅危险；**本季只见背影/侧脸/手**（不露全脸，终极悬念）。
- **性格底色**：控制狂，把所有人当棋子；"时间"是他真正的武器。
- **人物弧线**：本季纯阴影，第二季正面登场；他的"反预知"能力是**主角金手指的最大反制**。
- **核心欲望**：掌控时间、掌控大赛、掌控所有人。
- **核心恐惧**：吴真这种"开挂者"失控，威胁他的时间实验。
- **口头禅 / 习惯**：「别急，游戏还没开始。」；出现时画面色调转冷、BGM 压低（**反派阴影镜头语言**）。
