# 《格斗家世界》第一季 · 选题策划书

> 出品定位：现象级热血逆袭向 AI 短剧（穿越 + 预知金手指 + KOF 情怀杀 + 热血格斗）
> 版本：v1.0 | 单季时长：20 分钟（分镜 80 镜 / 每镜 15s）
> 编剧：墨烨（AI 短剧剧本专家）

---

## 一、一句话简介

一个玩遍 KOF 94→16 全系列的 30 岁程序员，被时光机意外送进 1994 年的 KOF 世界。
**他靠"游戏里背了二十多年的剧情"当金手指，在日本报名格斗家大赛，正面硬刚自己从小玩到大的偶像，卷入 KOF 背后的巨擘阴影，最终在"回家"与"留下"之间，成为改变历史的人。**

---

## 二、核心卖点（3 条爆款基因）

### 卖点 1｜「穿越 + 预知」双倍爽感，金手指有牙齿
主角不是无敌数值怪，而是"信息差金手指"：他记得 KOF 94→16 每一位格斗家的招式、克制、剧情走向。
**爽点**：他提前格挡了偶像的招牌必杀、精准预判对手出招，全片"开挂感"拉满。
**克制**（三道锁，防止爽过头变无聊）：
1. 他知道招式，但 94 年活人比游戏角色更快、更狠——**预知 ≠ 必胜**；
2. 剧情一旦被主角介入就会改写——**他越爽，历史越失控**；
3. 反派拥有"反预知"能力（能读他的下一步）——**金手指会被反制**。
> 这套"有牙齿的金手指"是本剧区别于"无脑爽文"的核心，也是第二季最大悬念的来源。

### 卖点 2｜KOF 情怀杀 + 老玩家"见活人"的极致浪漫
第一次让"草薙京、二阶堂红丸、椎拳崇、八神庵"从像素卡带变成会呼吸、会出拳、会对白的人物。
- 主角见到"活的草薙京"时那一瞬间的颤抖与狂喜，是 KOF 老粉的集体情绪核弹；
- "无式焚天 / 百鬼夜行 / 龙卷飓风"这些招牌必杀被逐一实战还原，**每招都是情怀+燃点的双重炸弹**。
> 情怀不是点缀，是本剧最强传播钩子——老粉会自发二创、截图、"我早说过了"式玩梗。

### 卖点 3｜热血逆袭 + 情感拉扯 + 强悬念反转，三曲线同频
- **逆袭曲线**：文弱社畜 → 94 年隐世高人指点 → 日本报名 → 惊艳全场的格斗家；
- **情感曲线**：兄弟情（拳馆）、偶像认可（拳崇赛后握手）、敌我模糊（八神庵/草薙京的杀机与善意反复横跳）；
- **悬念曲线**：回家无门、反派阴影、"别信草薙京"匿名信、"你到底想做什么"的终极对峙——**结尾强钩子直接锁死第二季**。

## 四、差异化定位

| 维度 | 市面同类 | 《格斗家世界》 |
|---|---|---|
| 金手指 | 无敌系统 / 数值膨胀 | **信息差预知**（有牙齿、可被反制） |
| IP 处理 | 魔改 / 洗白 | **忠实致敬 + 活人化还原**，招式名场面 1:1 |
| 情感 | 纯爽纯打 | 爽 + 热血兄弟情 + 偶像认可 + 敌我模糊三层情感 |
| 配音 | 普通话 | **粤语主音轨**，覆盖粤语区 + 港产味加分 |
| 悬念 | 单集小钩子 | 三层反转 + 终极悬念锁定第二季 |
| 形态 | 真人剧 | **AI 短剧**，AI 生成友好场景（拳馆/街道/擂台，无大场面战争） |

**定位一句话**：给老玩家的"情怀救赎片"，给新观众的"热血穿越爽剧"，一鱼两吃。

## 五、竞品分析

| 竞品 | 优势 | 我们的差异打法 |
|---|---|---|
| 同类穿越同人短剧 | 情怀先行 | 我们金手指有牙齿 + 招式实战还原度更高，爽感更有"含金量" |
| 国漫热血流（长篇） | 世界观完整 | 我们 20 分钟单季打"高密度"，单集爆点密度是长篇 2 倍 |
| 抖音/快手热血短剧 | 节奏快 | 我们用"信息差"驱动，不是靠无脑反转，质量更高、留存更好 |
| 港产/粤语内容 | 稀缺 | 粤语短剧格斗向近乎空白，先发即占位 |

## 六、爆款预判理由（为什么能爆）

1. **情怀共振**：KOF 系列横跨 94→2026，"活人化"是全网老粉从未被满足的核心愿望——**满足即传播**；
2. **爽点结构清晰**：穿越(开局爆点) → 金手指觉醒(爽) → 遇偶像(燃) → 惊艳全场(爽) → 虽败犹荣(虐+燃) → 终极悬念(钩)——**完整情绪过山车**；
3. **AI 短剧红利**：场景可控、人物可复用（资产库驱动），制作成本与更新速度碾压真人剧，**适合日更追更**；
4. **粤语卡位**：粤语区 + 港产味，差异化卡位，避免普通话红海内卷；
5. **续季可挖**：反派吉斯·南镇、大蛇线、音巢线、KOF 94→2026 全版本，**IP 可无限续写**。

> 预判：本剧具备"老粉自来水二创 + 新观众追爽点"双引擎，单季 20 分钟密度足以支撑"一口气看完"，**完播率与追更率双高**。

## 七、平台与档期建议

- **首发**：抖音 / 快手（快节奏、爆点密度高，15s 分镜天然适配）；粤语区主推视频号 + 港澳矩阵；
- **音轨**：普通话 + 粤语双音轨（本套脚本以粤语 TTS 为主产出，普通话音轨可后期补）；
- **节奏**：单季 20 分钟拆成 10 段（每段 2 分钟 / 8 镜）投放，每段结尾留钩子，制造"追着看下一段"；
- **续季**：第二季《KOF 巅峰战》——揭反派吉斯全脸、入大蛇线、R 组织邀请函。
